Full System Flow - Long-Context Underwater Video Understanding

Tracking objects and identifying temporal patterns across long underwater video - which model does which job

Ready-made tool / model Existing model, used in our own way Our own research part Offline / training (not in the live loop)
0. BEFORE RUNNING - TRAINING & LABELLING (offline, once)

A. Label data fast

SAM 2.1 / SAM 3
In: raw underwater videos
Out: boxes, masks, IDs (a person fixes mistakes)

B. Train the detector

YOLO26 / YOLO11 (Ultralytics)
In: SFISHTRACK, MFT25, BrackishMOT, FishTrack23
Out: underwater fish detector weights

C. Prepare re-ID network

V-JEPA 2.1 (ViT-L) or small ReID CNN
In: fish crops with track IDs
Out: appearance embedding model
▼
1. INPUT & PREPARATION (CPU)

1. Video input & decoding

FFmpeg / PyAV
In: long MP4 or live camera / ROV stream
Out: every frame + frame number + exact timestamp
Grouped into 10 s clips = work units only (saving, checkpoints). Nothing resets at a clip boundary.
▶

2. Water-quality check

OpenCV (no AI model)
In: each frame
Out: visibility score (contrast, sharpness, colour)
Used later to ignore alerts in bad visibility. Image enhancement only if tests show it helps.
▼
2. SEE & FOLLOW (GPU, every frame, in order)

3. Detection

YOLO (fine-tuned)
In: frames in batches of 8-16
Out: boxes, class (fish, turtle, crab, debris...), confidence
▶

4. Short-term tracking

BoT-SORT
In: boxes, frame by frame
Out: track IDs + track pieces (tracklets)
Keeps IDs for seconds. Corrects camera motion (ROV/AUV).
▶

5. Hard moments only

SAM 2.1 tiny/small
When: fish cross, overlap, half hidden, or ID is 'uncertain'
In: boxes just before the problem
Out: exact masks through the hard moment → fewer ID swaps
▼
3. REMEMBER WHO IS WHO (long-term identity)

6. Appearance fingerprint

SAM 2 mask + V-JEPA 2.1 / ReID CNN
In: fish crop, background removed by mask
Out: embedding vector per track piece
▶

7. Self-taught identity (STIM)

Our contrastive head (PyTorch)
In: track pieces of THIS video
Learns: same piece = same fish, same frame = different fish
Out: embeddings tuned to these exact fish
▶

8. Identity memory

Our linker (Hungarian + margin rule)
In: embeddings + position + time gap
Out: global IDs marked confirmed / probable / uncertain
Re-links fish after hiding. Refuses to guess when two fish look the same.
▼
4. UNDERSTAND TIME - EVENTS, PATTERNS, ALERTS (CPU, from the database)

9. Events

Python rules
Out: arrived, left, came back, group formed, visibility dropped - with timestamps
▶

10. Temporal patterns

pandas, SciPy (FFT), ruptures, HDBSCAN + DTW
Out: cycles, trends, change points, typical routes, recurring visits, event sequences
Reported as ranges when IDs are uncertain ("3-5 revisits").
▶

11. Health-gated alerts

Robust statistics
Out: unusual crowding, emptiness, odd movement, unknown objects
Ignored if visibility is bad or the tracker is breaking.
▼
5. DESCRIBE IN WORDS (GPU, separate worker, only important frames)

12. Keyframe picker

Event triggers + duplicate filter
In: events, patterns, alerts + 1 frame per 30-60 s
Out: a few sharp, non-repeating keyframes
▶

13. Vision-language model

Qwen3-VL 4B / 8B (quantised)
In: keyframes with IDs drawn + tracker facts
Out: what is happening, in plain words
Any text naming an ID the tracker never saw is rejected.
▶

14. Summaries in levels

Qwen3-VL (text)
Out: clip → 10-minute → whole-video summaries
▼
6. OUTPUT

15. Database & search

SQLite + FAISS
Holds: tracks, IDs, events, patterns, summaries
Search: by ID, time, event or plain text
▶

16. Annotated video

OpenCV + FFmpeg
In: ORIGINAL video re-read + final global IDs
Out: same length, same frames, boxes + IDs
▶

17. Dashboard

FastAPI + Streamlit
Shows: video player, timeline, patterns, summaries, alerts, ID search
Memory A - short-term
Live tracks, speed, recent appearance. In RAM. Steps 4-5.
Memory B - objects & events
Global IDs, paths, first/last seen, events. SQLite. Steps 8-11.
Memory C - meaning
Descriptions, summaries, search vectors. SQLite + FAISS. Steps 13-15.
Simple rule: YOLO finds → BoT-SORT follows → SAM 2 fixes hard moments → STIM + identity memory remember who is who → statistics find patterns → Qwen3-VL explains in words.
